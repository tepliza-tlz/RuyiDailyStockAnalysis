# Brand Assets for RuyiDailyStockAnalysis (如意金股)

## File Structure
```
docs/assets/dsa_vi/
  icon.svg          - Square icon for favicon/logo mark (64x64 viewBox)
  logo-light.svg    - Full horizontal logo for dark backgrounds
  logo-dark.svg     - Full horizontal logo for light backgrounds
  favicon.ico       - Multi-size ICO for legacy browsers
  png/              - PNG exports at 16/32/48/64/128/180/256/512px
  README.md         - This file

apps/dsa-web/public/brand/   - Web app copy (same files, for build inclusion)
```

## Design Rationale
- **Icon mark**: Abstract up-trend line (financial growth) + two dot nodes (AI/quantum) embedded in a dark rounded square
- **Color**: Deep blue (#2563eb) to gold (#c9a96e) gradient - tech meets finance
- **Typography**: Microsoft YaHei/PingFang SC for Chinese; Segoe UI/Arial for English
- **Minimal**: Clean lines, works at 16px favicon scale

## File Purposes
| File | Use |
|------|-----|
| icon.svg | Favicon source, app icon mark |
| logo-light.svg | Header, sidebar expanded (dark bg) |
| logo-dark.svg | Header, sidebar expanded (light bg) |
| favicon.ico | Legacy browser favicon |
